| 2026-09-02 | Receiving | WU4B / `nfl-receiving-share-x-efficiency-v2.0.0` (allocation `nfl-receiving-calibrated-ratio-shrinkage-share-v2.0.0`) | Replaces ONLY the receiving target-VOLUME leg. Prediction IDs change (model version + projection state change). v1 remains valid for every prediction archived under it.
